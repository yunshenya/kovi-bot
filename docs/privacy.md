# 数据与隐私说明

机器人会把聊天内容发送给部署者配置的模型服务；使用网页搜索、网页抓取或 MCP 工具时，
相关查询和必要上下文还会发送给对应服务。图片识别会将当前请求中的图片传给主模型或独立
视觉模型。新生成的身份元数据只使用当前显示名称等最少必要资料，不主动附带 QQ 号等账号
标识；但用户正文、图片、旧数据迁移出的记忆和历史摘要本身仍可能包含个人信息。部署者应
在启用前确认这些服务的地区、保留和训练政策，并向群成员告知。

## 本地持久化数据

PostgreSQL 保存长期记忆、用户档案、群组档案、滚动摘要、人格状态、表情标签、角色动作目标、跨群问答任务和 Agent Run。这些记录
可能包含 QQ 号、群号、昵称、消息片段、推断出的兴趣/情绪以及交互时间。表情标签只保存
OneBot 图片标识与文字标签，不保存图片文件；但标识仍可能属于个人数据。

`memory.retention_days` 默认是 30 天。后台维护会清理超过期限且重要性低于 7 的长期记忆。
用户/群档案默认 90 天未活跃到期，滚动摘要默认 30 天到期，表情标签默认 90 天未更新到期；
档案还分别设有 10000 个用户、2000 个群的运行上限。高重要性记忆不会单纯因为年龄到期，
但所有 V1 长期记忆仍受 `memory.max_entries`（默认 1000 条）约束。Mind Episode 情节记忆单独按
`memory.episode_retention_days`（默认 365 天）和 `memory.episode_max_per_scope`（默认每个作用域 128 条）维护；
年龄清理只删除已解决且 salience、情绪权重都低于 `memory.episode_protected_salience`（默认 0.7）的旧情节。
数量清理对 `resolved`/`unresolved` 已知状态执行硬上限，保护项按优先级保留；如果保护项本身超过上限，
也会从价值最低的已知记录开始淘汰。未知状态不参与淘汰并始终保留。

提醒任务只保留到投递完成、取消或失败；终态记录默认按记忆保留周期自动清理。删除用户或群
数据时会同步删除对应提醒，群聊中由用户创建的提醒也会随该用户删除。

跨群问答任务会保存主管理员 QQ 号、来源私聊消息、目标群、群内问题、收集截止时间、成员回复的
QQ 号、显示名称与文字、群问题消息 ID、回复是否引用问题/点名芸汐、轻量相关性标记和私聊汇报消息 ID。
成员回复只会在任务收集窗口内新增，普通命令、明显闲聊和与问题无关的文字不会进入任务事件表；任务终态按记忆
保留周期清理，同一群同时只允许一个收集任务。汇报模型只接收截断后的 data-only 回复资料，不获得跨群发送或
外部查询工具权限。主管理员可以查询任务状态，也可以在群问题和私聊汇报均未处于发送过程时取消未完成任务。

主管理员发起跨群动作时，`kovi_bot_agent_goals` 会保存操作者、来源私聊消息 ID、目标群、待发
正文、执行状态和成功后的 OneBot 消息 ID，用于幂等和审计。终态目标按记忆保留周期清理；
删除操作者数据或目标群数据时会同步删除对应目标。执行中断且无法确认是否已发送的动作不会
自动重放。

持续 Agent Run 会保存主管理员 QQ 号、来源私聊消息 ID、公开 URL、条件参数、执行间隔、截止时间、
受限的 HTTP 响应预览、状态码、错误摘要、事件日志、动作日志和最终私聊消息 ID。URL 查询参数及响应
预览可能包含敏感值，因此不要使用带长期密钥的 URL，也不要让监测接口返回不必要的个人数据。每个 Run
同时受截止时间、最大执行次数、连续失败次数、响应大小和并发数量限制；终态记录按记忆保留周期清理，
删除创建者数据时会级联删除 Run、事件和动作。最终私聊通知在发送前写入不可重放闸门；发送超时或进程
中断时只保存“投递结果不确定”，不会自动重复发送。

`memory.data_minimization = true` 是默认模式：档案字段、情绪历史、群成员列表、摘要和长期
对话正文会在写入边界截断并限制条数，表情标签只保存稳定标识和短文本。关闭该选项只能放宽
文本长度，不能绕过 TTL、删除、作用域隔离和容量上限。数据库备份仍须由部署者制定覆盖所有
表和备份的删除策略。

Redis 或进程内存只保存可重建的短期状态，例如回复/撤回候选、限流计数和等待图片标记。
私聊近期图片索引默认保留 1 小时、每用户最多 8 个引用；不保存图片文件，也不进入
PostgreSQL。进程崩溃时 Redis 中的短期键可能持续到各自 TTL 到期。

## 最小化与删除

- 只对白名单中的好友和群启用插件，按需要收紧 `retention_days`、各类 TTL、`max_entries` 和摘要长度。
- 为 PostgreSQL 磁盘与备份启用加密，并限制数据库账号、日志和备份的访问权限。
- 不在仓库、Issue、日志或错误截图中粘贴 Token、QQ 号、聊天正文或数据库导出。
- 私聊用户可发送 `#删除我的数据`，再发送 `#删除我的数据 确认`，删除其私聊长期记忆、
  用户档案、私聊摘要、近期图片索引、短期回复状态、角色动作目标、其创建的 Agent Run、其创建的跨群问答任务和其在
  其他任务中的成员回复，以及由其教学或归属于其私聊的表情标签。
- Kovi 管理员可在群内发送 `#删除本群数据`，再发送 `#删除本群数据 确认`，删除本群长期
  记忆、群档案、群摘要、短期回复状态、以本群为目标的角色动作、以本群为目标的跨群问答任务，
  以及归属于或来源于本群的表情标签。
- 历史群聊记忆以群为归属，没有保存可供可靠逐人删除的发送者字段；个人删除命令无法从
  这些聚合文本中准确剔除某位成员。收到这类请求时，应由管理员评估并删除整个群作用域。
- 应单独处理数据库备份和旧版迁移快照的保留；运行时命令不会追溯删除离线备份。
- 停用机器人时，应撤销模型/OneBot 密钥、删除数据库和备份，并检查 Redis 是否仍有键。

仓库提供上述删除命令，但不提供自动数据导出，也不能替代备份清理或对群聚合文本的人工
处置。部署者仍是数据处理范围、告知、访问请求和适用法律合规的责任方。
