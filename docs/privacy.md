# 数据与隐私说明

机器人会把聊天内容发送给部署者配置的模型服务；使用网页搜索、网页抓取或 MCP 工具时，
相关查询和必要上下文还会发送给对应服务。图片识别会将当前请求中的图片传给主模型或独立
视觉模型。新生成的身份元数据只使用当前显示名称等最少必要资料，不主动附带 QQ 号等账号
标识；但用户正文、图片、旧数据迁移出的记忆和历史摘要本身仍可能包含个人信息。部署者应
在启用前确认这些服务的地区、保留和训练政策，并向群成员告知。

## 本地持久化数据

PostgreSQL 保存长期记忆、用户档案、群组档案、滚动摘要、人格状态和表情标签。这些记录
可能包含 QQ 号、群号、昵称、消息片段、推断出的兴趣/情绪以及交互时间。表情标签只保存
OneBot 图片标识与文字标签，不保存图片文件；但标识仍可能属于个人数据。

`memory.retention_days` 默认是 30 天。后台维护会清理超过期限且重要性低于 7 的长期记忆，
并删除超过期限未活跃的用户/群档案及与其关联的滚动摘要；档案还分别设有 10000 个用户、
2000 个群的运行上限。高重要性记忆不会单纯因为年龄到期，但所有长期记忆仍受
`memory.max_entries`（默认 1000 条）约束。人格和表情标签不按该保留期自动到期。
因此需要统一、严格保留期限时，部署者仍须制定覆盖所有表和备份的删除策略。

Redis 或进程内存只保存可重建的短期状态，例如回复/撤回候选、限流计数和等待图片标记。
私聊近期图片索引默认保留 1 小时、每用户最多 8 个引用；不保存图片文件，也不进入
PostgreSQL。进程崩溃时 Redis 中的短期键可能持续到各自 TTL 到期。

## 最小化与删除

- 只对白名单中的好友和群启用插件，按需要收紧 `retention_days`、`max_entries` 和摘要长度。
- 为 PostgreSQL 磁盘与备份启用加密，并限制数据库账号、日志和备份的访问权限。
- 不在仓库、Issue、日志或错误截图中粘贴 Token、QQ 号、聊天正文或数据库导出。
- 私聊用户可发送 `#删除我的数据`，再发送 `#删除我的数据 确认`，删除其私聊长期记忆、
  用户档案、私聊摘要、近期图片索引、短期回复状态，以及由其教学或归属于其私聊的表情标签。
- Kovi 管理员可在群内发送 `#删除本群数据`，再发送 `#删除本群数据 确认`，删除本群长期
  记忆、群档案、群摘要、短期回复状态，以及归属于或来源于本群的表情标签。
- 历史群聊记忆以群为归属，没有保存可供可靠逐人删除的发送者字段；个人删除命令无法从
  这些聚合文本中准确剔除某位成员。收到这类请求时，应由管理员评估并删除整个群作用域。
- 应单独处理数据库备份和旧版迁移快照的保留；运行时命令不会追溯删除离线备份。
- 停用机器人时，应撤销模型/OneBot 密钥、删除数据库和备份，并检查 Redis 是否仍有键。

仓库提供上述删除命令，但不提供自动数据导出，也不能替代备份清理或对群聚合文本的人工
处置。部署者仍是数据处理范围、告知、访问请求和适用法律合规的责任方。
