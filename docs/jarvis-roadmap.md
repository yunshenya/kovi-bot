# 个人贾维斯 Roadmap（kovi-bot → 你的 Jarvis）

> 目标：把一个"有灵魂的 QQ 聊天机器人"变成**只属于你的、常驻的、替你观察世界并主动帮忙的 AI 伙伴**——像贾维斯那样懂你的世界，又有 neuro-sama 那股"活人味儿"。
>
> **核心原则：不改写 `yunxi-core`。** 最难的部分（持久身份/记忆/情绪/关系/Mind/自主/主动/人格一致性）已经做好。剩下的工作是给它"喂世界"、"给身体"、"以你为中心"。全部通过**新增宿主适配层**和**调用现有 `observe_world_fact` 等 seam** 实现。

---

## 阶段 0 — 以你为中心（把它从"群聊机器人"变成"你的伙伴"）

**目标**：让系统默认服务**你一个人**，把"讨好观众/群聊随机推送"降为可关的旁路。

- **代码**：配置层面，不用改核心。
- **步骤**：
  1. 强化 `[identity].owner_person_id` 为唯一活跃对象；主管理员=你。
  2. 新增 `[companion] single_owner_mode`：开启后禁用/收敛 群聊插话(`[group_interjection]`)、随机主动推送(`[proactive].push_probability_percent`)、跨群动作；主动只对 owner 目标。
  3. 部署默认 `single_owner_mode = true`；README 说明"个人陪伴配置"。
- **验证**：设 owner + 单主人模式后，机器人只与你交互；无群聊自动接话；主动消息只面向你。
- **风险**：低。**大小**：半天。

## 阶段 1 — 世界传感器（喂它你的真实世界）

**目标**：把"你的世界"作为一等事件喂进核心。agent-run（URL）已经接入；扩展到你环境的其他信号。

- **代码**：插件侧新的 `world_sensors` 模块 + 复用现有调度/限流。
- **步骤**：
  1. **1a. 通用"世界传感器"框架**：一个有界后台调度器，按间隔检查一组可配置传感器（文件存在/变更、命令退出码、URL 状态、日历事件），在状态变化时调 `observe_world_fact(owner_scope, summary, importance, watch=true)`。
  2. **1b. 真实传感器**：URL（已有 agent-run）；再加 **文件/构建状态** 和 **日历/日程** 各一个最小样例。
  3. 传感器遵守 `[traffic]`/`[agent_runs]` 的资源上限；检查结果去重、幂等。
- **验证**：传感器检测到状态变化 → 核心记忆里有该事实 →（watch=true）存在对应开环 → 之后可能被主动提起。
- **风险**：中（新调度 + 状态）。**大小**：1–2 周。

> 示例：盯 `kovi-bot` 的 CI 状态，失败时 `watch=true` 喂一条世界事实，她之后会主动说"你的构建挂了一阵子"。

---

## 阶段 2 — 世界感知的认知（让核心"在意"你的世界）

**目标**：不只是"记住"，而是让世界事实真正影响她的关心与主动性。

- **代码**：`mind_runtime.rs`（Reflection/consolidation）、`core_model.rs`（回复上下文）、`open_loop_scheduler.rs`。
- **步骤**：
  1. Reflection 在整合世界事实记忆时，把相关世界事实**微调**到对应的 `Interest`/`Agenda`/`Belief`（她开始"关心"你的项目）。
  2. 回复上下文注入近期**世界事实**（她"知道"你的 build 挂了 / 那件事有结果了）。
  3. 确保 `watch` 开环在主动选择中**公平竞争**（salience/冷却/上下文共同决定是否真的说出口）。
- **验证**：记录一条世界事实 → 她的 Mind 出现对应的兴趣/议程增量；她在合适时机主动提起。
- **风险**：中。**大小**：1 周。

---

## 阶段 3 — 身体（桌面 + 语音 + 常驻在场）—— 最大的工程

**目标**：一个**常驻的**桌面身体，持续看到你的世界、主动说话。这是"贾维斯感"的分水岭。

- **代码**：新宿主（不走 Kovi/QQ），复用 `yunxi-core` 的 port 层（`SendMessage`/`ReachOut` 动作 → 声音/皮套；`SendMessage` 落为"说话 + 表情"）。
- **步骤**：
  1. **3a. 最小桌面文字外壳**：用 Tauri/egui 起一个常驻窗口，把 `yunxi-cli` 的 Core 接入换成 GUI 宿主（读核心状态、提交世界事件、渲染回复）。
  2. **3b. 世界持续输入**：桌面宿主把"你的环境事件"（剪贴板/聚焦窗口/文件活动/截图）作为 WorldEvents 喂核心；核心的 world/socket 观察持续运行。
  3. **3c. 语音 + 皮套**：用 `reporter.observe_model_output` 的流式 hook 把生成 token 推给 **TTS 声音 + Live2D 皮套**（口型/表情/动作），`SendMessage` 落为"说话 + 动皮套"。
  4. 可选：让核心"看"自己的屏幕——用 `CORE_VISION`（已有本地 MiniMind-3o 视觉）对周期性截图做场景理解，喂成世界观察。
- **验证**：桌面窗口常驻；她说话（TTS）；可视化皮套随语气/情绪变化；她能主动报告世界事件（"你的构建恢复了"）。
- **风险**：高（新宿主、新模态）。**大小**：3–6 周，建议拆 3a→3b→3c 三个里程碑。

---

## 阶段 4 — 自主与权限转向（"服务器" → "伙伴"）

**目标**：从"你显式建 agent-run/提醒"到"她理解你、主动提议帮你盯着/做事"。

- **代码**：`agent_runs`/`reminders`/`tool_access` 的授权边界 + 对话驱动的创建。
- **步骤**：
  1. 允许她在**你的私聊里**基于对话提议建立监听/提醒（"要我一直盯着这个吗？"），你确认后生效。
  2. 工具白名单默认只读/安全；**不可逆动作必须经你显式确认**；跨主体访问保持主管理员闸门。
  3. 保持所有自主动作有界（配额/冷却/截止），并记审计。
- **验证**：她提议一个监听 → 你确认 → 命中后她主动汇报；不做任何未经确认的不可逆操作。
- **风险**：中（授权改动）。**大小**：1–2 周。

---

## 阶段 5 — 人格打磨（贾维斯的魂）

**目标**：把 persona 从"温柔群聊女孩"调成"忠诚、懂你、能说会道、站在你这边的军师/伙伴"。

- **代码**：`config/prompt.rs` 的锚点与护栏 + `SelfModel` 的 values/traits + `affect_tone_guidance` 阈值。
- **步骤**：
  1. 重写 persona 锚点 + `ValueProfile`（坦诚/好奇/忠诚/独立/玩心）为贾维斯味。
  2. 提供 2–3 个"语气档"（内敛/均衡/外放），由 affect/relation 决定（可复用 `affect_tone_guidance`）。
  3. 迭代 tone 阈值，让"活"但别"演"。
- **验证**：同一件事在不同状态/关系下，她的语气和主动性自然不同；有观点、有分寸。
- **风险**：低。**大小**：1 周。

---

## 阶段 6 — 加固、隐私、运维

**目标**：一个"知道很多关于你"的常驻伙伴，数据和资源都要安全、有界、可审计。

- **代码**：`docs/privacy.md`、数据最小化、成本/配额上限、CI（已有）。
- **步骤**：
  1. 补"世界事实"进数据最小化与删除边界（`#删除我的数据` 一并清世界事实/开环）。
  2. 给自主/主动循环加**每日成本/调用预算**（复用现有 `main_admin_daily_limit` 思路，改为 owner 预算）。
  3. 桌面/语音先确认本地 vs 云端推理的隐私边界；本地 MiniMind 作为默认（离网）。
  4. 跑现有 CI + `cargo deny/audit`。
- **验证**：CI 全绿；资源有界；可删数据；文档覆盖世界事实。
- **风险**：低。**大小**：1 周。

## 依赖与建议执行顺序

```
阶段0 (以你为中心) ———> 阶段1 (世界传感器) ———> 阶段2 (世界认知)
                                │
                                └────────────> 阶段3 (身体/桌面/语音) ——> 阶段4 (自主/权限)
                                                                        │
                                                             阶段5 (人格打磨) + 阶段6 (加固)
```

- **最快见效**：阶段 0 + 阶段 1 + 阶段 2 —— 让她"知道你世界里的关键事"，这是"懂你"的第一步，且全部能复用现有 seam。
- **分水岭**：阶段 3（身体）—— 做完它，她才会"在场"，才真正接近"你的贾维斯"。
- **MVP（2 周可跑的"懂你的伙伴"）**：阶段 0 + 1a + 1b（URL/CI 一个传感器）+ 2。效果：她持续知道你世界的走向，并能在合适时机主动告诉你。

## 贯穿始终的三条红线

1. **人格从状态合成，不写死**：persona = 稳定锚点（self-model/values/核心 traits）+ 活层（affect/relation/energy），每轮合成；别把"你该表现了"写死进 prompt。
2. **主动始终有界**：所有自主/主动动作受配额、冷却、截止约束；不刷屏、不烧钱、不失控。
3. **以你为中心 + 最小权限**：默认只服务 owner；不可逆动作需确认；不暴露内部协议；数据可删。
